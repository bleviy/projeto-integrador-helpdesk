# Sistema de Gestão de Chamados e Suporte Técnico

Projeto Integrador – Laboratório de Programação
Universidade Santo Amaro – UNISA

## Descrição

Sistema de Help Desk desenvolvido em Python para gerenciamento de chamados de suporte técnico.

## Funcionalidades

- Login de usuários
- Abertura de chamados
- Listagem de chamados
- Busca por ID
- Atualização de status
- Atribuição de técnico
- Persistência de dados em JSON

## Como executar

1. Instale o Python 3.
2. Baixe o arquivo helpdesk.py.
3. Abra o terminal na pasta do arquivo.
4. Execute:

python helpdesk.py
